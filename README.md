# Portfólio Pessoal | Lucas Teles de Sousa

Este é o repositório do meu portfólio web pessoal, desenvolvido para apresentar minha trajetória profissional, conhecimentos técnicos e projetos práticos. Sou estudante de Engenharia de Software e atuo como Estagiário de Suporte de TI, aliando minha base operacional de infraestrutura à resolução de problemas no desenvolvimento de software.

## Estrutura e Funcionalidades

O projeto é uma Single Page Application (SPA) totalmente responsiva, contendo as seguintes seções:

* **Sobre Mim:** Introdução sobre minha carreira e transição da área de suporte para o desenvolvimento.
* **Tecnologias:** Demonstração das linguagens e ferramentas com as quais trabalho.
* **Projetos:** Uma galeria interativa de aplicações que venho desenvolvendo, contando com modais informativos, listagem de tecnologias e links diretos para os repositórios.
* **Experiências:** Linha do tempo detalhando minhas atuações profissionais.
* **Contatos:** Links diretos para meu GitHub, LinkedIn, E-mail e WhatsApp.

## Tecnologias Utilizadas no Portfólio

* **React.js:** Biblioteca JavaScript para construção da interface baseada em componentes.
* **Tailwind CSS:** Framework CSS utilitário utilizado para toda a estilização, animações e responsividade.
* **React Type Animation:** Utilizado para o efeito de digitação dinâmico e contínuo no cabeçalho de apresentação.
* **Intersection Observer API:** Lógica de visualização customizada (`FadeInSection`) para animar os componentes à medida que o usuário rola a página.

## Projetos em Destaque

Alguns dos principais projetos integrados e explicados neste portfólio:

1. **Cadastro Usuário - CRUD:** API RESTful desenvolvida em Java com o framework Spring Boot para gerenciamento de usuários.
2. **Totem de Suporte:** Sistema de autoatendimento para abertura de chamados utilizando Java, Spring Boot, MySQL e JPA/Hibernate.
3. **Sistema de Gerenciamento de Materiais:** Aplicação desktop focada em gestão de estoque desenvolvida em Python com banco de dados SQLite3.
